# Cover illustrations

Ten 640 × 400 SVG covers used on the Notes page, the subject sidebars, the
Articles, Interactive and Projects pages. They are generated by `scripts/generate_covers.py`; edit the
script and re-run it rather than editing the SVGs by hand.

Shared system: a pale gradient background with two soft glows and a faint dot
grid; ink `#2c5a69`, teal `#3f8597`, sky `#8cc2d3`, blush `#df93aa`, gold
`#e0ac58`; 2–3.5px rounded strokes over translucent gradient fills. Main
subjects sit in the centre 400 × 360 so the square sidebar crop and the 16:9
article crop both keep them.

## Note thumbnails

`notes/<subject>/*.svg` are the 400 × 400 thumbnails on the subject pages,
generated by `scripts/generate_thumbnails.py` in the same system with heavier
strokes (they display at about 190px). Subjects stay inside y 70–330 because
phones crop the square to a wide strip. To add a note, write a function in
that script, register it in `THUMBS`, run it, and point the card's `<img>` at
the new file.
